# (c) Computing the Convex Hull Using Andrew's Monotone Chain Algorithm

## Main Idea

After converting all rectangles into corner points, we need to find the outer boundary around those points.

This outer boundary is the convex hull.

The algorithm used here is **Andrew's Monotone Chain Algorithm**.

It works by:

```text
1. Sorting all points.
2. Building the lower hull.
3. Building the upper hull.
4. Combining both hulls.
```

---

## Why Sorting the Points Is Needed

The algorithm needs to process points from left to right.

So all points are sorted:

```text
first by x-coordinate
then by y-coordinate if x values are equal
```

Example:

```text
Before sorting:
(4,2), (0,0), (4,0), (0,2)

After sorting:
(0,0), (0,2), (4,0), (4,2)
```

Diagram:

```text
y
↑
|
|       (0,2) ●────────────● (4,2)
|             │            │
|             │            │
|       (0,0) ●────────────● (4,0)
|
+--------------------------------→ x
```

Sorting helps the algorithm scan points in a clean direction:

```text
left side → right side
```

This makes it possible to build the bottom boundary and top boundary separately.

---

## Lower Hull

The lower hull is the bottom part of the convex hull.

```text
y
↑
|
|       ●                ●
|        \              /
|         \            /
|          ●──────────●
|
+--------------------------------→ x
```

The lower hull is built by scanning the sorted points from left to right.

While adding points, the algorithm checks whether the last three points make a correct outer turn.

If a point creates an inward bend, that point is removed.

---

## Upper Hull

The upper hull is the top part of the convex hull.

```text
y
↑
|
|          ●──────────●
|         /            \
|        /              \
|       ●                ●
|
+--------------------------------→ x
```

The upper hull is built by scanning the sorted points in reverse order, from right to left.

It uses the same turn-checking method as the lower hull.

---

## Cross Product / Orientation Test

To decide whether a point should stay on the hull, the algorithm uses the cross product.

For three points:

```text
O = (Ox, Oy)
A = (Ax, Ay)
B = (Bx, By)
```

The formula is:

```text
cross(O, A, B)
= (Ax - Ox)(By - Oy) - (Ay - Oy)(Bx - Ox)
```

Meaning:

```text
cross > 0  → left turn / counter-clockwise
cross < 0  → right turn / clockwise
cross = 0  → collinear
```

---

## How Cross Product Builds the Hull

Suppose the current hull has two points:

```text
O → A
```

Now we want to add a new point `B`.

The algorithm checks:

```text
O → A → B
```

If this creates an inward bend, `A` is removed.

Example of an inward bend:

```text
y
↑
|
|       O ●────────────● B
|          \          /
|           \        /
|            \      /
|             ● A
|
+--------------------------------→ x
```

The path:

```text
O → A → B
```

bends inward.

The better outer boundary is:

```text
O → B
```

So point `A` is removed.

---

## Stack-Like Idea

The hull is built like a stack.

```text
Add a point.
Check the last three points.
If the middle point creates an inward turn, remove it.
Repeat until the boundary is correct.
```

Simple flow:

```text
hull = []

for each point:
    add point to hull

    while last three points make a wrong turn:
        remove the middle point
```

This removes inside points and keeps only the outer boundary points.

---

## Combining Lower and Upper Hull

After building both parts:

```text
lower hull = bottom boundary
upper hull = top boundary
```

They are joined together:

```text
convex hull = lower hull + upper hull
```

Example:

```text
y
↑
|
|          ●──────────●
|         /            \
|        /              \
|       ●                ●
|        \              /
|         \            /
|          ●──────────●
|
+--------------------------------→ x
```

The final hull is a closed outer polygon.

---

## Algorithm Steps

```text
1. Convert every rectangle into four corner points.
2. Put all corner points into one list.
3. Sort the points by x, then y.
4. Remove duplicate points.
5. Build the lower hull.
6. Build the upper hull.
7. Combine lower and upper hulls.
8. Calculate the perimeter of the hull.
```

---

## Time Complexity

Let:

```text
N = number of rectangles
```

Each rectangle gives 4 points.

So:

```text
P = 4N
```

where `P` is the number of points.

Creating all points:

```text
O(N)
```

Sorting all points:

```text
O(P log P)
```

Building the lower and upper hulls:

```text
O(P)
```

Calculating the perimeter:

```text
O(P)
```

Since:

```text
P = 4N
```

the total time complexity becomes:

```text
O(N log N)
```

The sorting step is the main reason for the `log N` part.

---

## Why This Algorithm Is Suitable

The input can contain up to 200,000 rectangles.

That means up to:

```text
4 × 200000 = 800000 points
```

A slow algorithm such as checking every point against every other point would be too expensive.

Andrew's monotone chain is suitable because it computes the convex hull efficiently in:

```text
O(N log N)
```

This matches the required expected complexity.
