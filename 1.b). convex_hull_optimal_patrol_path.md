# (b) Why the Convex Hull of All Rectangle Corners Is the Optimal Patrol Path

## Main Idea

The robot must patrol around all rectangular machines.

The path must:

```text
1. Be a closed loop.
2. Contain every rectangle inside it or on its edge.
3. Not pass through the inside of any rectangle.
4. Have the shortest possible total length.
```

The shortest valid path is the boundary of the **convex hull** of all rectangle corner points.

---

## What Is a Convex Hull?

Imagine every rectangle corner is a nail on a board.

Then imagine stretching a rubber band around all nails.

The rubber band touches only the outermost nails and forms the smallest convex boundary around all points.

That boundary is the convex hull.

```text
y
↑
|
|              ●────────────●
|             /              \
|            /                ●
|           /                 |
|      ●───●                  |
|       \                     |
|        ●────────────────────●
|
+------------------------------------------------→ x
```

The points inside the rubber band do not change the outside boundary.

---

## Why Rectangle Corners Are Enough

Each rectangle is axis-aligned and fully determined by its four corners.

Example rectangle:

```text
y
↑
|
|       A ●────────────● B
|         │            │
|         │ rectangle  │
|       D ●────────────● C
|
+----------------------------→ x
```

If a path contains:

```text
A, B, C, D
```

then the whole rectangle is inside or on the boundary.

So if the patrol path contains all rectangle corner points, it contains all rectangles.

---

## Why the Convex Hull Is Valid

The convex hull contains all rectangle corner points.

Since every rectangle lies between its four corners, the convex hull also contains every rectangle.

So the convex hull path is valid because:

```text
All rectangle corners are inside/on the hull.
Every rectangle is formed from its corners.
Therefore every rectangle is inside/on the hull.
```

---

## Why the Convex Hull Gives the Shortest Outer Path

A patrol path must enclose all rectangles.

After converting rectangles into points, the path must enclose all corner points.

Among all convex closed boundaries that contain a set of points, the convex hull is the smallest one.

If a path has an inward dent, it is not the shortest outer boundary.

Example of an inward dent:

```text
y
↑
|
|       ●────────────●
|        \          /
|         \        /
|          ●      /
|         /      /
|        /      /
|       ●──────●
|
+----------------------------→ x
```

The middle inward point creates a longer path than directly connecting the outer points.

The shorter boundary removes the inward dent:

```text
y
↑
|
|       ●────────────●
|        \          /
|         \        /
|          \      /
|           \    /
|            \  /
|             ●
|
+----------------------------→ x
```

So a shortest enclosing path will not contain inward dents.

A shape with no inward dents is convex.

The smallest convex shape containing all points is the convex hull.

---

## Inside Points Do Not Matter

Some rectangle corners may be inside the final outer boundary.

Example:

```text
y
↑
|
|       ●────────────────●
|       │                │
|       │      ●──●      │
|       │      │  │      │
|       │      ●──●      │
|       │                │
|       ●────────────────●
|
+--------------------------------→ x
```

The small rectangle inside does not affect the outer patrol path.

The robot does not need to bend inward to visit inside corners.

The path only needs to surround all rectangles.

---

## Convex Hull Boundary as the Patrol Path

The robot's path is the boundary of the convex hull.

If the hull points are:

```text
P0, P1, P2, P3, ..., Pk
```

then the robot moves:

```text
P0 → P1 → P2 → P3 → ... → Pk → P0
```

This creates a closed polygonal path.

```text
y
↑
|
|             P3 ●
|              /  \
|             /    \
|       P2 ●        ● P4
|          │        │
|          │        │
|       P1 ●────────● P0
|
+--------------------------------→ x
```

The total length of this boundary is the minimum patrol path length.

---

## Final Reasoning

```text
Rectangles are represented by their corners.
The patrol path must contain all rectangle corners.
The convex hull is the smallest convex boundary containing all points.
A shortest outer path cannot have inward dents.
Therefore the optimal patrol path is the convex hull boundary.
```
