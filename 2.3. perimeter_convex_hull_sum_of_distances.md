# Perimeter as the Sum of Distances Along the Convex Hull

In coordinate geometry, the **perimeter** of a polygon is the total length around its boundary.

In this problem, after finding the convex hull, the robot's patrol path is the boundary of that convex hull.

So the required path length is the perimeter of the convex hull.

---

## Convex Hull as an Ordered List of Points

Assume the convex hull has these points in order:

```text
P0, P1, P2, P3, ..., Pk
```

These points are connected one after another:

```text
P0 → P1 → P2 → P3 → ... → Pk
```

Because the path is a closed loop, the last point must connect back to the first point:

```text
Pk → P0
```

So the full boundary is:

```text
P0 → P1 → P2 → P3 → ... → Pk → P0
```

---

## XY Diagram

Example convex hull:

```text
y
↑
|
|                 P3
|                ●
|              /   \
|            /       \
|       P2 ●          ● P4
|          |          |
|          |          |
|       P1 ●──────────● P0
|
+--------------------------------→ x
```

The perimeter is the total distance around the outside:

```text
P0 → P1
P1 → P2
P2 → P3
P3 → P4
P4 → P0
```

---

## Distance Between Two Consecutive Hull Points

For any two consecutive hull points:

```text
Pi = (xi, yi)
Pj = (xj, yj)
```

The distance between them is:

```text
distance(Pi, Pj)
= sqrt((xj - xi)^2 + (yj - yi)^2)
```

This distance is calculated using the Euclidean distance formula.

---

## Perimeter Formula

If the convex hull points are:

```text
P0, P1, P2, ..., Pk
```

then the perimeter is:

```text
perimeter =
distance(P0, P1)
+ distance(P1, P2)
+ distance(P2, P3)
+ ...
+ distance(Pk-1, Pk)
+ distance(Pk, P0)
```

The final term:

```text
distance(Pk, P0)
```

is needed because the polygon is a closed loop.

---

## Compact Mathematical Form

If there are `m` hull points:

```text
P0, P1, P2, ..., Pm-1
```

then the perimeter can be written as:

```text
perimeter = Σ distance(Pi, P(i+1) mod m)
```

where:

```text
i = 0 to m - 1
```

The modulo part means:

```text
After the last point, go back to the first point.
```

So:

```text
P(m-1 + 1) mod m = P0
```

This closes the polygon.

## Numerical Example

Suppose the convex hull points are:

```text
P0 = (0, 0)
P1 = (4, 0)
P2 = (4, 2)
P3 = (0, 2)
```

This forms a rectangle:

```text
y
↑
|
|  P3(0,2) ●──────────● P2(4,2)
|          |          |
|          |          |
|  P0(0,0) ●──────────● P1(4,0)
|
+--------------------------------→ x
```

The perimeter is:

```text
distance(P0, P1)
+ distance(P1, P2)
+ distance(P2, P3)
+ distance(P3, P0)
```

Calculate each distance:

```text
distance(P0, P1)
= distance((0,0), (4,0))
= sqrt((4 - 0)^2 + (0 - 0)^2)
= sqrt(16)
= 4
```

```text
distance(P1, P2)
= distance((4,0), (4,2))
= sqrt((4 - 4)^2 + (2 - 0)^2)
= sqrt(4)
= 2
```

```text
distance(P2, P3)
= distance((4,2), (0,2))
= sqrt((0 - 4)^2 + (2 - 2)^2)
= sqrt(16)
= 4
```

```text
distance(P3, P0)
= distance((0,2), (0,0))
= sqrt((0 - 0)^2 + (0 - 2)^2)
= sqrt(4)
= 2
```

So:

```text
perimeter = 4 + 2 + 4 + 2
```

```text
perimeter = 12
```

## Example With a Slanted Edge

Convex hull edges are not always horizontal or vertical. Some edges can be slanted.

Example:

```text
y
↑
|
|              P2(7,5)
|                ●
|              / |
|            /   |
|          /     |
| P0(1,1) ●──────● P1(4,1)
|
+--------------------------------→ x
```

The slanted edge is:

```text
P1 → P2
```

Let:

```text
P1 = (4, 1)
P2 = (7, 5)
```

Distance:

```text
distance(P1, P2)
= sqrt((7 - 4)^2 + (5 - 1)^2)
```

```text
distance(P1, P2)
= sqrt(3^2 + 4^2)
```

```text
distance(P1, P2)
= sqrt(9 + 16)
```

```text
distance(P1, P2)
= 5
```

So even when the hull edge is slanted, the same Euclidean distance formula is used.

---

## Use in the Patrol Path Problem

The robot moves along the boundary of the convex hull.

If the convex hull has points:

```text
P0, P1, P2, ..., Pm-1
```

then the robot travels:

```text
P0 → P1 → P2 → ... → Pm-1 → P0
```

The minimum patrol path length is:

```text
sum of all these edge distances
```

So the perimeter formula gives the final answer that must be printed by the program.
