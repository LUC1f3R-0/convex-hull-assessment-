# (a) Transforming the Rectangle Problem Into a Point Problem

## Main Idea

The original problem gives rectangular machines on a 2D `x-y` coordinate plane.

Instead of directly working with full rectangles, we transform every rectangle into its **four corner points**.

After that, the problem becomes:

```text
Given many points, find the shortest closed boundary around all of them.
```

That boundary is found using the convex hull.

---

## Rectangle on an XY Plane

A rectangle has four corners.

```text
y
↑
|
|        top-left              top-right
|           ●────────────────────●
|           │                    │
|           │                    │
|           │                    │
|           ●────────────────────●
|     bottom-left           bottom-right
|
+------------------------------------------------→ x
```

Each corner is a coordinate point:

```text
(x, y)
```

---

## Input for One Rectangle

The input gives one rectangle using four numbers:

```text
x1 y1 x2 y2
```

These are two opposite, diagonal corners of the rectangle.

So:

```text
First corner  = (x1, y1)
Second corner = (x2, y2)
```

Example:

```text
0 0 4 2
```

This gives:

```text
(0, 0) and (4, 2)
```

These are opposite corners.

---

## Finding the Four Corners

Because the rectangle is axis-aligned, its sides are parallel to the `x` and `y` axes.

So from the two opposite corners, we can find:

```text
left   = min(x1, x2)
right  = max(x1, x2)
bottom = min(y1, y2)
top    = max(y1, y2)
```

Then the four corners are:

```text
(left, bottom)
(left, top)
(right, bottom)
(right, top)
```

---

## Example

Input rectangle:

```text
0 0 4 2
```

So:

```text
x1 = 0, y1 = 0
x2 = 4, y2 = 2
```

Calculate:

```text
left   = min(0, 4) = 0
right  = max(0, 4) = 4
bottom = min(0, 2) = 0
top    = max(0, 2) = 2
```

The four corners are:

```text
(0, 0)
(0, 2)
(4, 0)
(4, 2)
```

Diagram:

```text
y
↑
|
|       (0,2) ●────────────● (4,2)
|             │            │
|             │            │
|       (0,0) ●────────────● (4,0)
|
+--------------------------------→ x
```

---

## For Many Rectangles

If there are `N` rectangles, each rectangle gives 4 corner points.

```text
1 rectangle  → 4 points
2 rectangles → 8 points
3 rectangles → 12 points
N rectangles → 4N points
```

Example:

```text
2
1 1 4 3
5 9 7 5
```

Rectangle 1:

```text
(1,1), (1,3), (4,1), (4,3)
```

Rectangle 2:

```text
(5,5), (5,9), (7,5), (7,9)
```

All points together:

```text
(1,1), (1,3), (4,1), (4,3),
(5,5), (5,9), (7,5), (7,9)
```

---

## Why This Transformation Helps

A rectangle is fully determined by its four corners.

If a closed path contains all four corners of a rectangle, then it contains the whole rectangle, because the rectangle lies inside the boundary formed by those corners.

So instead of solving:

```text
Find the shortest path around many rectangles.
```

We solve:

```text
Find the shortest path around all rectangle corner points.
```

This is now a point-based geometry problem.

---

## Final Transformation

```text
Rectangles
    ↓
Two opposite corners for each rectangle
    ↓
Four corner points for each rectangle
    ↓
One large set of points
    ↓
Convex hull of all points
```
