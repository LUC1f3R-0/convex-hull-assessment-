# Euclidean Distance Between Two Points

In coordinate geometry, the Euclidean distance is the straight-line distance between two points on the XY plane.

Let the two points be:

```text
A = (x1, y1)
B = (x2, y2)
```

The distance between `A` and `B` is the length of the straight line segment connecting them.

---

## XY Diagram

```text
y
↑
|
|                         B(x2, y2)
|                         ●
|                       / |
|                     /   |
|                   /     |  vertical difference
|                 /       |  = y2 - y1
|               /         |
|  A(x1, y1) ●────────────●
|
|          horizontal difference
|          = x2 - x1
|
+----------------------------------------→ x
```

The line from `A` to `B` forms the hypotenuse of a right triangle.

The horizontal side length is:

```text
x2 - x1
```

The vertical side length is:

```text
y2 - y1
```

The straight-line distance is the hypotenuse.

---

## Formula

Using Pythagoras' theorem:

```text
hypotenuse² = horizontal² + vertical²
```

So:

```text
distance(A, B)
= sqrt((x2 - x1)^2 + (y2 - y1)^2)
```

Using point notation:

```text
distance(A, B)
= sqrt((B.x - A.x)^2 + (B.y - A.y)^2)
```

---

## Why This Formula Works

From point `A` to point `B`, there are two changes:

```text
horizontal change = x2 - x1
vertical change   = y2 - y1
```

These two changes form a right triangle.

```text
          B
          ●
         /|
        / |
       /  | vertical change
      /   |
     /    |
A   ●─────●
   horizontal change
```

By Pythagoras' theorem:

```text
distance² = horizontal change² + vertical change²
```

Therefore:

```text
distance = sqrt(horizontal change² + vertical change²)
```

Which gives:

```text
distance(A, B)
= sqrt((x2 - x1)^2 + (y2 - y1)^2)
```

---

## Numerical Example

Let:

```text
A = (1, 1)
B = (4, 5)
```

Find the horizontal and vertical differences:

```text
x2 - x1 = 4 - 1 = 3
y2 - y1 = 5 - 1 = 4
```

Apply the formula:

```text
distance(A, B)
= sqrt((4 - 1)^2 + (5 - 1)^2)
```

```text
distance(A, B)
= sqrt(3^2 + 4^2)
```

```text
distance(A, B)
= sqrt(9 + 16)
```

```text
distance(A, B)
= sqrt(25)
```

```text
distance(A, B) = 5
```

So the straight-line distance between `(1, 1)` and `(4, 5)` is:

```text
5
```

---

## Diagram of the Example

```text
y
↑
|
|                 B(4,5)
|                   ●
|                 / |
|               /   |
|             /     | 4
|           /       |
| A(1,1) ●──────────●
|             3
|
+--------------------------------→ x
```

Here:

```text
horizontal difference = 3
vertical difference   = 4
distance              = 5
```

This is the common `3-4-5` right triangle.

---

## Use in the Patrol Path Problem

After finding the convex hull, the patrol path is made of straight line segments.

If two consecutive hull points are:

```text
P1 = (x1, y1)
P2 = (x2, y2)
```

then the length of that edge is:

```text
distance(P1, P2)
= sqrt((x2 - x1)^2 + (y2 - y1)^2)
```

The total patrol path length is found by adding the distances of all hull edges.
