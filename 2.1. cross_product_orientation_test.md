# Cross Product / Orientation Test of Three Points

In coordinate geometry, the cross product / orientation test is used to identify the direction formed by three points.

Let the three points be:

```text
O = (Ox, Oy)
A = (Ax, Ay)
B = (Bx, By)
```

We observe the movement:

```text
O → A → B
```

The question is:

```text
When moving from O to A, does point B make the path turn left, turn right, or stay on the same straight line?
```

---

## XY Diagram

```text
y
↑
|
|                  B
|                 ●
|
|          A
|         ●
|
|   O
|  ●
|
+--------------------------------→ x
```

Here, `O`, `A`, and `B` are points on the 2D XY plane.

---

## Vector Meaning

From point `O`, we can create two vectors:

```text
Vector OA = A - O
Vector OB = B - O
```

So:

```text
OA = (Ax - Ox, Ay - Oy)
OB = (Bx - Ox, By - Oy)
```

The 2D cross product of these two vectors is:

```text
cross(O, A, B)
= (Ax - Ox)(By - Oy) - (Ay - Oy)(Bx - Ox)
```

Using point notation:

```text
cross(O, A, B)
= (A.x - O.x) * (B.y - O.y)
- (A.y - O.y) * (B.x - O.x)
```

---

## Meaning of the Result

The sign of the cross product tells the orientation of the three points.

```text
cross(O, A, B) > 0  → left turn / counter-clockwise turn
cross(O, A, B) < 0  → right turn / clockwise turn
cross(O, A, B) = 0  → collinear points
```

---

## Case 1: Left Turn

If the cross product is positive, point `B` is on the left side of the directed line `O → A`.

```text
y
↑
|
|          B
|         ●
|        /
|       /
|  O ●────────● A
|
+----------------------------→ x
```

In this case:

```text
cross(O, A, B) > 0
```

So the points make a counter-clockwise turn.

---

## Case 2: Right Turn

If the cross product is negative, point `B` is on the right side of the directed line `O → A`.

```text
y
↑
|
|
|  O ●────────● A
|       \
|        \
|         ● B
|
+----------------------------→ x
```

In this case:

```text
cross(O, A, B) < 0
```

So the points make a clockwise turn.

---

## Case 3: Collinear Points

If the cross product is zero, the three points lie on the same straight line.

```text
y
↑
|
|
|  O ●────────● A────────● B
|
+----------------------------→ x
```

In this case:

```text
cross(O, A, B) = 0
```

So `O`, `A`, and `B` are collinear.

---

## Numerical Example

Let:

```text
O = (0, 0)
A = (4, 0)
B = (4, 2)
```

Using the formula:

```text
cross(O, A, B)
= (Ax - Ox)(By - Oy) - (Ay - Oy)(Bx - Ox)
```

Substitute the values:

```text
cross(O, A, B)
= (4 - 0)(2 - 0) - (0 - 0)(4 - 0)
```

```text
cross(O, A, B)
= 4 × 2 - 0 × 4
```

```text
cross(O, A, B)
= 8
```

Since:

```text
8 > 0
```

the points form a left turn.

Diagram:

```text
y
↑
|
|              B(4,2)
|                ●
|                |
|                |
|  O(0,0) ●──────● A(4,0)
|
+----------------------------→ x
```

---

## Area Meaning

The absolute value of the cross product is equal to twice the area of triangle `OAB`.

```text
Area of triangle OAB = |cross(O, A, B)| / 2
```

So if:

```text
cross(O, A, B) = 0
```

then:

```text
Area = 0
```

That means the three points do not form a real triangle. They lie on one straight line.
